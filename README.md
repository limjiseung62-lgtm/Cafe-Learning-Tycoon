# 카페 학습 타이쿤 · v1.1.0

[카페 열기](https://limjiseung62-lgtm.github.io/Cafe-Learning-Tycoon/)

문제를 풀어 음식을 만들고 손님에게 서빙하며 카페를 키우는 초등 학습 게임입니다.

## 플레이

1. 수업 게임 또는 저장해서 이어가는 내 카페 키우기를 선택합니다.
2. 음식 만들기에서 문제를 풀면 실제 생산된 음식 이미지와 수량이 표시됩니다.
3. 카페로 돌아오면 모든 해금 메뉴의 재고를 선반에서 확인할 수 있습니다.
4. 직원이 없으면 준비된 주문의 서빙 버튼을 한 번 누릅니다. 사장님이 픽업부터 배달까지 수행합니다.
5. 직원을 고용하면 자동 서빙합니다. 메뉴·직원·아이템·창고·확장을 비교하고 카페를 키웁니다.

화면과 문제창을 열어도 영업 시간은 계속 흐릅니다. 내 카페 저장은 같은 브라우저에 남습니다. v1.0.0의 저장 형식과 승인된 경제 수치, 문제은행 원본82+쌍둥이82, 오답 복습, 특수손님·아이템·아트·폰트·음향을 유지합니다.

## 검증과 안내

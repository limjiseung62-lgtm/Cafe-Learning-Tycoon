# 카페 학습 타이쿤 · v1.2.1

[카페 열기](https://limjiseung62-lgtm.github.io/Cafe-Learning-Tycoon/)

문제를 풀어 음식을 만들고 손님에게 서빙하는 초등 학습 게임입니다.

- 수업 게임: 매번 같은 작은 카페에서 시작해 Lv.6까지 키웁니다.
- 내 카페 키우기: 같은 브라우저에서 저장하고 Lv.10까지 이어갑니다.
- 직원 0명은 준비된 주문의 서빙하기를 눌러 사장이 직접 운반합니다. 고용 후에는 사장과 직원이 자동으로 처리합니다.
- 도움 손님 10종과 Lv.4 이상의 드문 특별 주문이 추가되었습니다. 특별 문제도 전체 문제 수에 포함되며 정답 음식 생산과 오답 복습을 유지합니다.

영업 시간과 손님 대기는 문제풀이 중에도 흐릅니다. 저장은 사용 중인 브라우저에 보관됩니다. 기존 저장 스키마 1을 그대로 이어가며 기존 수업 경제·메뉴18종·원본82+쌍둥이82 문제팩을 유지했습니다.

181개 자동검사, TypeScript 검사, production build, 실제 브라우저 검수 통과. 60분 균형/합리적 운영 모델의120문제 결과는 Lv.5 75% / Lv.6 25%입니다. 육성 효율 운영 3개 시드는 회당15분·30문제·정답률90%에서71~74회에Lv.10에 도달했습니다. 모델 수치는 개인 플레이의 결과를 보장하지 않습니다. 모바일 실물 기기 검증을 의미하지 않습니다.
